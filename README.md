    <h1>✨ OmniPanel</h1>
    <p><strong>OmniPanel is a desktop overlay application designed to simplify complex game controls by simulating input from a secondary, non-focusable touchscreen monitor.</strong></p>
    <p>No more memorizing dozens of keybinds—just a couple of intuitive graphical buttons on your screen.</p>

    <hr>

    <h2>💡 The Core Concept: Overlay Controls</h2>
    <p>OmniPanel's primary innovation is that it does <strong>not steal focus</strong> from your main game.</p>
    <ul>
        <li>You run your game on your primary monitor.</li>
        <li>OmniPanel runs on your secondary touchscreen monitor.</li>
        <li>You tap buttons on the secondary screen, and the simulated keystrokes are sent directly to your game, allowing you to <strong>keep playing normally</strong> without interrupting the game window's active input state.</li>
    </ul>

    <h2>⚙️ Customization (Theming and Input)</h2>
    <p>OmniPanel is built around community-driven theming. All configuration is done via local files:</p>
    <ul>
        <li><strong>Themes:</strong> Change the look and feel of your controls by editing or swapping out the HTML, CSS, and asset files in the <code>user/themes/</code> directory.</li>
        <li><strong>Keybinds:</strong> Edit the theme's configuration file to map on-screen buttons to specific keyboard or mouse inputs for your favorite games.</li>
    </ul>
